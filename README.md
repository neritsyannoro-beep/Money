# Деньги — учёт расходов

Мобильный трекер расходов. Открывается с домашнего экрана как обычное приложение,
работает без интернета, ничего никуда не отправляет: все данные лежат только на твоём телефоне.

## Приложение или сайт?

Это **PWA** — сайт, который добавляется на домашний экран и после этого ведёт себя как приложение:
своя иконка, полный экран без адресной строки, запуск и работа без интернета.

Почему так, а не «настоящий» apk/ipa:

| | PWA (этот вариант) | Нативное приложение |
|---|---|---|
| Установка | добавить на экран за 15 секунд | App Store / Google Play, ревью, аккаунт разработчика ($99/год у Apple) |
| Обновления | сам подтягивает новую версию | нужно выкладывать релиз и ждать проверки |
| Где работает | iPhone, Android, ноутбук — одинаково | под каждую платформу отдельная сборка |
| Офлайн | да | да |

Для личного трекера расходов PWA — правильный выбор: разницы в использовании нет,
а возни на порядок меньше.

## Как установить на телефон

Сначала сайт нужно опубликовать (см. ниже), потом:

**iPhone (Safari).** Открой ссылку в Safari → кнопка «Поделиться» → **«На экран “Домой”»** → «Добавить».
Важно: именно Safari, из Chrome на iOS добавить нельзя.

**Android (Chrome).** Открой ссылку → меню «⋮» → **«Установить приложение»** (или «Добавить на главный экран»).

После этого приложение запускается с иконки, на весь экран и работает в самолёте.

## Публикация (GitHub Pages, бесплатно)

Код уже лежит в ветке `main`. Остаётся один раз включить хостинг:

1. Открой репозиторий на GitHub → **Settings** → в левом меню **Pages**.
2. В блоке *Build and deployment* выбери **Source: Deploy from a branch**,
   ветка **`main`**, папка **`/ (root)`** → **Save**.
3. Подожди минуту и обнови страницу — вверху появится адрес вида
   **`https://neritsyannoro-beep.github.io/Money/`**. Это и есть ссылка на приложение.

Дальше каждый пуш в `main` обновляет сайт сам. Открывать ссылку нужно с телефона —
и добавлять на домашний экран по инструкции выше.

Локально:

```bash
python3 -m http.server 8000   # затем открыть http://localhost:8000
```

(Просто открыть `index.html` двойным кликом не даст работать офлайн-режиму:
service worker требует http/https.)

## Что умеет

**Ввод за три касания.** Плюс → сумма на большой цифровой клавиатуре → категория → «Добавить».
Дата по умолчанию сегодняшняя, «Вчера» и «Позавчера» — в один тап, любая другая — через календарь.

**Суммы считаются сами.** Итог за день / неделю / месяц / всё время пересчитывается сразу после ввода,
у каждого дня в списке — свой подытог. Стрелками (или свайпом влево-вправо) листаешь периоды назад:
на «Дне» это «Сегодня» → «Вчера» → любая дата, на «Месяце» — прошлый месяц.

**Категории — свои.** Добавляй, переименовывай, меняй эмодзи и цвет. Новую категорию можно создать
прямо из формы траты, не теряя введённую сумму. При удалении категории траты не пропадают — переезжают в «Прочее».

**Отчёт.** Кольцевая диаграмма, разбивка по категориям с процентами, средний чек, траты в день,
самый дорогой день, топ-5 крупнейших трат и сравнение с прошлым периодом («↑ 23% к прошлому»).
Тап по категории — все траты внутри неё.

**Лимиты.** Можно задать лимит на месяц и на неделю — под суммой появится полоса «осталось столько-то»,
при перерасходе она краснеет.

**Мелочи, которые важны в ежедневном использовании:** удаление с кнопкой «Отменить», тёмная тема
(следует за системной), лёгкая вибро-отдача на нажатия, выбор валюты ($, €, ₽, ֏, ₾, ₸, ₴, £, ₺, AED),
начало недели с понедельника или воскресенья.

## Данные

Хранятся в `localStorage` браузера — только на этом устройстве. Ни сервера, ни аккаунта, ни аналитики.

Из-за этого:

- очистка данных сайта в браузере сотрёт историю трат;
- на другом телефоне будет пустое приложение.

Поэтому в настройках есть **выгрузка резервной копии (JSON)** и **загрузка копии из файла** —
так история переносится на новое устройство. Ещё есть выгрузка в **CSV**, если захочется покрутить цифры в таблице.
Копию удобно делать раз в месяц и кидать себе в облако или в избранное в мессенджере.

## Как это устроено

Ноль зависимостей и ноль сборки — четыре файла, которые можно открыть и прочитать:

```
index.html            разметка экранов
styles.css            оформление, светлая и тёмная темы
app.js                вся логика: хранение, периоды, отчёты, шторки
sw.js                 service worker — работа без интернета
manifest.webmanifest  описание приложения для установки на экран
icons/                иконки для домашнего экрана
```

Суммы хранятся в копейках/центах целыми числами — без ошибок округления, которые бывают у дробных чисел.

Чтобы обновить установленное приложение после правок в коде: подними номер версии кэша в `sw.js`
(`money-v1` → `money-v2`) — service worker подтянет свежие файлы.
